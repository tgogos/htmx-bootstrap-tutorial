4. Decide where the HTML goes

Lesson 2 always replaces whatever is in the slot. hx-swap is the instruction for where the response goes relative to the target. The request and the card stay the same.

What changed

Both buttons use the lesson 2 card URL and the same target. Only hx-swap differs. innerHTML replaces the children of #book-shelf. beforeend inserts the card after the last child and leaves what was already there. HTMX also accepts the name append for that second style.

The markup

{% if book %} 
<button hx-get=".../card" hx-target="#book-shelf" hx-swap="innerHTML">Replace</button>
<button hx-get=".../card" hx-target="#book-shelf" hx-swap="beforeend">Add to the shelf</button>
{% endif %}

Both buttons still call lesson_book_card. That function has no parameter for hx-swap, so both get the same tutorial/book_card.html. HTMX reads the attribute on the button you clicked and places that HTML after it arrives.

return templates.TemplateResponse(
    request,
    "tutorial/book_card.html",
    {"book": book},
)

Request, response, target, swap

  • Request: the same GET as lesson 2.
  • Response: the same card fragment.
  • Target: #book-shelf for both buttons.
  • Swap: innerHTML replaces the shelf's contents. beforeend adds inside the shelf, at the end.

Other placements, for later: afterbegin adds at the start of the target, beforebegin and afterend put the HTML outside it, and outerHTML replaces the target element itself.

Experiment

Click Add to the shelf twice, then Replace once. In the inspector, change the Add button's hx-swap from beforeend to outerHTML and click it. The shelf element is gone, so a second click has no target left.
