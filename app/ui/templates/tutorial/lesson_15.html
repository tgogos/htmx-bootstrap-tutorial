15. A link swaps the main region and leaves the shell

Lesson 1's link loads a whole page. Lesson 2 asks for a fragment. This link asks for a whole page, then keeps only #main. The top bar and the sidebar stay.

Try it

Type a word in the search box in the top bar. Then click the link. The word is still there. The text of this lesson is replaced by the other room.

Open the other room

What changed

The new attributes are hx-boost and hx-select. hx-boost="true" turns the link into a request and still uses its href. Without JavaScript the same address loads as a normal page. A boosted link targets body unless you name somewhere else, which would replace the top bar and the sidebar. hx-target="#main" names the main region. hx-select="#main" takes that region out of the full page the server sent. hx-swap="outerHTML" replaces the #main element with the one from the response. The address becomes /ui/tutorial/15/room. Back loads this lesson again as a whole page, so the top bar is drawn again and the word is gone.

The attributes sit on the link. HTMX 4 does not copy them onto a child from a parent.

The markup and the page

<a
  href="/ui/tutorial/15/room"
  hx-boost="true"
  hx-target="#main"
  hx-select="#main"
  hx-swap="outerHTML"
>Open the other room</a>

GET /ui/tutorial/15/room is lesson_boost_room. It returns tutorial/room.html inside the same shell as this lesson: a full document, with its own #main. The route does not look at HX-Request. Lesson 11 returns a fragment when that header is set. Here the response is always the whole page, and hx-select is what leaves the shell alone. A boosted request also sends HX-Boosted: true.

Request, response, target, swap

  • Request: GET /ui/tutorial/15/room, with HX-Request and HX-Boosted.
  • Response: the whole other-room page, including the shell.
  • Target: #main. hx-select keeps that element from the response.
  • Swap: outerHTML, so the new #main replaces the old one.

Experiment

In the inspector, delete hx-select and click the link again. The main region fills with a whole page, shell and all, because nothing told HTMX to keep only #main. Reload, then open /ui/tutorial/15/room with the normal link. The top bar is drawn again, and the word you typed is gone.
