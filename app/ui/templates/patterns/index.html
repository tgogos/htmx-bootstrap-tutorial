Patterns

These pages come after lessons 1–15. Each one is still one idea.

They use the same books as the books table: the first eight titles. That table does not change. Checking a row here does not check it there.

  1. Select — a checkbox on each row. Nothing is sent.
  2. Mark — the checked ids go to the server, and the table is replaced.
  3. Out of band — the same action, and hx-swap-oob updates the line above the table.
  4. Keep the selection — the new table is merged in, so checks you still want can stay.
  5. Delete — confirm, then the count and the merge from the two pages before.
  6. Export — a bar that asks again until the job is finished.

The files for these pages live in app/ui/templates/patterns/. The routes are app/ui/patterns_routes.py.
