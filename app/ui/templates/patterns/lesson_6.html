What changed

The table is not the target. The button includes #pattern-form, so the checked ids are sent, and the response lands in #export-job. That fragment has hx-trigger="every 1s". Each response moves the bar one step. The server does not wait. When the bar is full, the fragment has no every, so the asking stops.

Request, response, target, swap

  • Request — POST /ui/patterns/6/export, then GET /ui/patterns/6/export once a second
  • Response — the bar, then the same bar a step further
  • Target — #export-job
  • Swap — innerHTML

Try this

Check one or two books and click Export selected. Watch the bar reach 100%, then stop. The books are unchanged.
