6. Search as you type

Lesson 5 waits until you finish choosing. A search box should update while you type, but not on every key, and not with an answer for a query you have already moved past.

On this page a one-letter search is held for 1.2 seconds on purpose, so you can see an older answer arrive last. The books list does not sleep.

Try it

This box does not cancel the previous search.

This box drops an in-flight search when you type again.

What changed

The new piece on both boxes is hx-trigger. keyup changed delay:300ms waits until you pause, and it skips the request when the text did not change (arrow keys, for example). The search event covers the clear button on a search field. The second box adds one attribute: hx-sync="this:replace". That aborts the request already running on this input and starts the new one. Without it, both requests finish, and whichever response arrives last is what you see — even if that response is for an older, shorter query.

The markup

<input
  type="search"
  name="q"
  hx-get="/ui/tutorial/books?slow=1"
  hx-trigger="keyup changed delay:300ms, search"
  hx-target="#fresh-results"
  hx-swap="innerHTML"
  hx-sync="this:replace"
>

The route is the same list as lesson 5. name="q" adds the text you typed. slow=1 is only for this lesson: a query of one character sleeps 1.2 seconds, and the fragment says so. The input stays outside the target, so the response cannot wipe out the letters you are still typing.

Request, response, target, swap

  • Request: GET /ui/tutorial/books?slow=1&q=... after a 300ms pause.
  • Response: the title list. A one-letter search also includes the artificial-wait line.
  • Target: the results element under that box, not the input.
  • Swap: innerHTML. hx-sync is not a swap. It decides whether the previous request is allowed to finish.

Experiment

In the left box, type a, wait until the request starts, then type nimal and pause again. You may see matches for "animal" and then the one-letter list replace them, because the slow response finishes last. Do the same in the right box. The one-letter request is cancelled, so that late list does not appear.
