5 · Delete

Delete selected sends the checked ids, after the same confirm dialog as lesson 8. The books leave the catalog.

{% include "patterns/stage.html" %}

What changed

The button waits for confirmed-delete, then posts the form. The count uses the extra fragment from pattern 3. The table uses innerMorph from pattern 4, so a box you left checked on a row you did not delete can stay.

Request, response, target, swap

  • Request — POST /ui/patterns/5/delete, after you confirm
  • Response — the table without those rows, plus the count line
  • Target — #pattern-board, and #available-count by id
  • Swap — innerMorph for the table, hx-swap-oob for the count

Try this

Check one book you can spare and click Delete selected. Confirm. That row is gone, and the line above matches the table that remains.
