Learn HTMX on a working app

These pages use HTMX 4.0.0. The reference is four.htmx.org.

Each lesson is one small interaction with a book. The books table is the advanced example at the end of the sequence. Start with lesson 1, not with that table.

Lessons you can open now

  1. A normal link — the browser already knows how to ask the server for a new page.
  2. A button that fetches one book — hx-get, an HTML fragment, and a target.
  3. A slow response and a spinner — the same fetch, plus hx-indicator.
  4. Where the HTML goes — hx-swap replaces the shelf, or adds to it.
  5. A category menu — hx-trigger and the value sent with the request.
  6. Search as you type — wait for a pause, and cancel a slower older request.
