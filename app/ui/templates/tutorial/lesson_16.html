16. The table morphs in place

Lesson 4 replaces the shelf or adds a card. Both throw the old HTML away and insert new HTML. This page fetches the same small table twice. One swap still throws it away. The other updates the table that is already there.

Try it

Type a word in the note. Click Replace. The word is gone, and the built time changes. Type the word again. Click Morph. The built time changes. The word is still in the note.

{% include "tutorial/morph_table.html" %}

What changed

The new swap is innerMorph. innerHTML removes the children of #title-table and inserts the response, so the note is a new box and the word is gone. innerMorph updates the elements that are already there. The note's id="shelf-note" is how HTMX knows it is the same box. The response sends that box empty, and the word you typed stays. The built time still changes, so you can see the table was updated. The buttons stay outside #title-table. In HTMX 2, hx-ext="morph" lived on a parent, often body, and an Idiomorph script lived beside HTMX. HTMX 4 removed hx-ext. The morph lives in app/ui/static/js/htmx.min.js, and on this page it lives on the Morph button as hx-swap="innerMorph". The books table still uses innerHTML.

The markup and the fragment

<button hx-get="/ui/tutorial/16/table" hx-target="#title-table" hx-swap="innerHTML">Replace</button>
<button hx-get="/ui/tutorial/16/table" hx-target="#title-table" hx-swap="innerMorph">Morph</button>

GET /ui/tutorial/16/table is lesson_morph_table in app/ui/tutorial_routes.py. It returns tutorial/morph_table.html: the note, the first five titles in title order, and the UTC time when the server built the fragment. It does not sleep. This URL is only that table. It is not the books table, and it does not change the address.

Request, response, target, swap

  • Request: GET /ui/tutorial/16/table from either button.
  • Response: tutorial/morph_table.html, the note and the titles.
  • Target: #title-table for both buttons.
  • Swap: innerHTML replaces the children. innerMorph patches them. Only the swap differs.

Experiment

In the inspector, delete id="shelf-note" from the note, type a word, and click Morph. The word is gone. Nothing ties the old box to the new one, so HTMX replaces it. Reload to get the id back.
