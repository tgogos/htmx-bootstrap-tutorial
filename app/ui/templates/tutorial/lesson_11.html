11. The books table is the same ideas, together

Lesson 10's shelf is a small list with an address. Books is that pattern with search, more columns, editing, and a toast. One route serves both the full page and the fragment.

Try it

Open the books table

The fragment will appear here. It has no sidebar, because it is not a page.

What changed

Nothing new is invented here. The button is lesson 2: hx-get a URL and swap the response. The link is lesson 1: the same URL, as a full page. books_page in app/ui/books_routes.py calls _wants_books_partial. That function returns partials/books_table.html when HX-Request is set, and books.html when you open the address or when HX-History-Restore-Request is set. That is the lesson 10 rule, on /ui/books.

The button targets #books-panel because the sort and page links inside the fragment already do. Those links do not know they were fetched onto this lesson. If this box had another id, a page arrow would not find #books-panel, and HTMX would put the next table inside the arrow instead of replacing this box. Those arrows also push the books address, so the bar leaves this lesson.

Where each earlier lesson shows up

  • Search. templates/books.html keeps the search box outside #books-panel. The trigger is keyup changed delay:300ms, and hx-push-url puts the query in the address. Lesson 6, plus lesson 10.
  • Sort and pages. partials/sortable_th.html and partials/list_pagination.html are links with href, hx-get, and hx-push-url, aimed at #books-panel. Ordering is an allowlisted name such as title or -author. The leading minus means descending. Lesson 10.
  • Rows per page. The size menu is not a link. app.js calls htmx.ajax when it changes, and the menu carries hx-indicator. Lessons 3 and 9: a small script where a swap is not enough.
  • Add. The form posts to /ui/books and targets #books-panel. A bad form returns the table HTML with status 400, which HTMX 4 still shows. Lesson 7.
  • Edit and delete. partials/book_row.html loads an edit form with hx-swap="outerHTML", and delete waits for confirmed-delete. A saved edit and a confirmed delete both set HX-Trigger so app.js shows a toast. Lessons 8 and 9.

Request, response, target, swap

  • Request: GET /ui/books from the button, or the same URL from the link.
  • Response: partials/books_table.html for the button. books.html, the whole shell, for the link.
  • Target: #books-panel for this button and for the links inside the table. The books page uses that same id.
  • Swap: innerHTML.

Experiment

Click the button and confirm the response has a table and no sidebar. Then open /ui/books?page=2&ordering=author. Click another column, then press Back. The address and the table should both return to author order, page 2.
