8. Change a book, and confirm before deleting it

Lesson 7 can add a book. It cannot change one, and a delete button that fires immediately is too easy to hit.

This page uses one practice book, ISBN tutorial-practice. It is created again if you delete it and reload. The sample shelf is left alone.

Try it

{% include "tutorial/practice_card.html" %}

Editing and deleting require an editor or an admin. The demo login is an admin.

What changed

Edit is another hx-get. It replaces the card with a form. Save is hx-put, the same idea as lesson 7's post, aimed at one book. A blank title comes back as the form plus the error alert, status 400.

Delete does not run on click. The button listens for confirmed-delete. A small script already on every page (app.js) opens the confirm dialog when you click a button marked js-confirm-delete. If you confirm, that script fires confirmed-delete on the button, and only then does HTMX send DELETE. Cancel closes the dialog and sends nothing.

Delete is not a form, so there is no hidden field to carry the token. The same script copies the token from the page header onto the request. Lesson 9 looks at the other half of that script.

The markup

<button
  class="js-confirm-delete"
  data-confirm="Delete ...?"
  hx-delete="/ui/tutorial/books/{{ book.id }}"
  hx-trigger="confirmed-delete"
  hx-target="#practice-slot"
  hx-swap="innerHTML"
>Delete</button>

GET .../edit renders tutorial/book_edit.html. PUT /ui/tutorial/books/<id> renders the card again, or the form with an error. DELETE renders tutorial/deleted.html.

Request, response, target, swap

  • Request: GET the edit form, PUT the fields, or DELETE after you confirm.
  • Response: the form, the card, or a short deleted message.
  • Target: #practice-slot for all three.
  • Swap: innerHTML. The confirm dialog is not a swap. It only decides whether the delete request is sent.

Experiment

Click Delete, then Cancel in the dialog. The card should still be there, and the network panel should show no delete. Confirm on a second try, then reload the page to get the practice book back.
