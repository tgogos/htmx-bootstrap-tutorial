5 · Delete

Delete selected sends the checked ids, after the same confirm dialog as lesson 8. The books leave the catalog.

{% include "patterns/stage.html" %}
Delete removes the book from the catalog, the same list as /ui/books. Check a row you can spare.

What changed

On pattern 2 the form owns the request. Here the button does. A click does not post. The button is marked js-confirm-delete, so the same dialog as lesson 8 opens. Confirm fires confirmed-delete on the button, and that is the trigger. Cancel sends nothing.

hx-include="closest form" is what still sends the checked ids. The button is not a submit, so HTMX would otherwise post an empty request. The count is the out-of-band fragment from pattern 3. The table uses innerMorph from pattern 4.

The markup

<form id="pattern-form">
  <button
    type="button"
    class="js-confirm-delete"
    hx-post="/ui/patterns/5/delete"
    hx-trigger="confirmed-delete"
    hx-include="closest form"
    hx-target="#pattern-board"
    hx-swap="innerMorph"
  >Delete selected</button>
  <input type="checkbox" id="select-…" name="book_id" value="…">
</form>

The response leaves out the rows you deleted, and marks the count out of band:

<form id="pattern-form">
  <tr id="pattern-row-kept">
    <input type="checkbox" id="select-kept" name="book_id" value="kept">
  </tr>
</form>
<p id="available-count" hx-swap-oob="outerHTML"><strong>7</strong> available</p>

innerMorph drops a row whose id is no longer in the response. A box you left checked on a row that is still there keeps its id, so that check stays. The count line is replaced by id, the same way as pattern 3.

Request, response, target, swap

  • Request — POST /ui/patterns/5/delete, after you confirm
  • Response — the table without those rows, plus the count line
  • Target — #pattern-board, and #available-count by id
  • Swap — innerMorph for the table, hx-swap-oob for the count

Try this

Check one book you can spare and click Delete selected. Confirm. That row is gone, and the line above matches the table that remains.
