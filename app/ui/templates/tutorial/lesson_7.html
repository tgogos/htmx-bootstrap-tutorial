7. Send a form, and get HTML back when it is wrong

Lessons 1–6 only read the catalog. This form asks the server to save a book. If the form is incomplete, the server refuses and still sends HTML that explains why.

Try it

A saved book, or an error, will appear here. The form stays put.

Saving requires an editor or an admin. The demo login is an admin.

What changed

The request is hx-post, not hx-get. A form's default trigger is submit, written out here so you can see it. The fields travel in the body, including a hidden csrf_token. That value was already on the page. The server checks it so some other site cannot submit this form as you. The form is outside #add-result, so an error does not wipe out what you typed.

The markup and the response

<form
  hx-post="/ui/tutorial/books"
  hx-target="#add-result"
  hx-swap="innerHTML"
  hx-trigger="submit"
>
  <input type="hidden" name="csrf_token" value="...">
  ...
</form>
<div id="add-result"></div>

POST /ui/tutorial/books reads the title, author, and year. When they are acceptable it renders tutorial/saved_card.html with status 200. When they are not, it renders tutorial/form_error.html with status 400. HTMX 4 still places that HTML into #add-result. A 400 used to be ignored by HTMX 2, so the message would never have appeared.

That choice is lesson_add_book in app/ui/tutorial_routes.py. HTMX does not pick the file. It puts whichever HTML comes back into the target.

payload, form_error = _parse_simple_book(title, author, year)
if form_error or payload is None:
    return templates.TemplateResponse(
        request, "tutorial/form_error.html",
        {"message": form_error}, status_code=400,
    )
book = await books_repo.create_book(...)
return templates.TemplateResponse(
    request, "tutorial/saved_card.html", {"book": book},
)

Request, response, target, swap

  • Request: POST /ui/tutorial/books with the form fields.
  • Response: a card when the book is saved, or an alert when it is not. The alert comes with status 400.
  • Target: #add-result.
  • Swap: innerHTML.

Experiment

Leave the title blank and save. In the network panel the status is 400, and the alert still shows up in the page. Then fill in a title and author, put a word in Year, and save again.
