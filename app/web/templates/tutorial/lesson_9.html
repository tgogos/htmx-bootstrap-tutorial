9. A message that is not part of the swap

Lesson 8 puts the result into #practice-slot. A toast is a note in the corner. It should not replace the book, so it cannot be the swapped HTML.

Try it

{{ book.title }}

What changed

The button posts, and hx-swap="none" tells HTMX to leave the page as it is. The response body is empty. The server also sends a header, HX-Trigger, whose value names an event, showToast, and a message. HTMX fires that event. It does not know how to draw a toast.

The drawing lives in app/web/static/js/app.js. That file is the small JavaScript island: confirm dialogs, toasts, and copying the token onto requests. The toast part listens for showToast and asks Bootstrap to show one. HTMX stays in charge of the request. The island only handles a widget the swap cannot express.

The markup and the header

<button
  type="button"
  hx-post="/ui/tutorial/books/{{ book.id }}/announce"
  hx-swap="none"
>Show a toast</button>

POST /ui/tutorial/books/<id>/announce returns no HTML. Its HX-Trigger header looks like {"showToast": {"message": "...", "level": "ok"}}. There is no form around the button, so the island copies the token from the page header, the same way lesson 8's delete does.

Request, response, target, swap

  • Request: POST the announce URL.
  • Response: an empty body, plus the HX-Trigger header.
  • Target: none that matters. Nothing is inserted.
  • Swap: none. The toast is a separate event, handled by app.js.

Experiment

Click the button and watch the corner of the page. Then open the announce response in the network panel. The body is empty. The message is only in the HX-Trigger header.
