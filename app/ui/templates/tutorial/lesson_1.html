1. A link is already a request

Before HTMX does anything, the browser can ask the server for a new page. This lesson is that request, with no hx- attributes. The tutorial home lists the folders these paths come from. The Files table at the bottom names the ones this lesson uses.

Try it

{% if book %}

Open {{ book.title }}

{% else %}
The catalog is empty. Run make seed, then reload this page.
{% endif %}

What this shows

Clicking the link navigates away from this lesson. The address bar changes. The response is a whole page: the admin shell, plus the book. The browser throws away this page and draws the new one. The Back button returns here because the browser stored this address.

The markup

{% if book %} 
<a href="/ui/tutorial/books/{{ book.id }}">Open {{ book.title }}</a>
{% endif %}

The route GET /ui/tutorial/books/<id> renders tutorial/book_page.html inside layout.html. It returns HTML, not JSON. /api/books is the JSON API and is not used here.

Request, response, target, swap

  • Request: the browser GETs the link URL. HTMX is not involved, so there is no HX-Request header.
  • Response: a full HTML document.
  • Target: the browser window. There is no element id.
  • Swap: none. The new document replaces the old one.

Experiment

Open the book, then press the browser Back button. You should land on this lesson again, with the same address you started from.
