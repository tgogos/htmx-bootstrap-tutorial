2. Ask for a fragment, and put it somewhere

Lesson 1 replaced the whole window. This button stays on this page. HTMX asks for a piece of HTML and writes it into one element.

What changed

The control is a button, not a link. The address bar does not change. The response is not a document: it is the card markup only. hx-target names the element that receives it. hx-swap="innerHTML" replaces that element's contents and leaves the element itself in place.

The markup and the response

{% if book %} 
<button
  type="button"
  hx-get="/ui/tutorial/books/{{ book.id }}/card"
  hx-target="#book-slot"
  hx-swap="innerHTML"
>Show {{ book.title }}</button>

<div id="book-slot">...</div>
{% endif %}

GET /ui/tutorial/books/<id>/card renders tutorial/book_card.html and nothing else. The same session rule as the rest of /ui still applies: you have to be logged in.

That response is lesson_book_card in app/ui/tutorial_routes.py. It does not use _lesson_ctx, and book_card.html does not extend layout.html. That is why the network panel shows a card and no sidebar. This lesson page is a different function, lesson_fetch, and that one does use the shell.

book = await books_repo.get_book(book_id)
return templates.TemplateResponse(
    request,
    "tutorial/book_card.html",
    {"book": book},
)

Request, response, target, swap

  • Request: GET the card URL. HTMX adds HX-Request: true.
  • Response: an HTML fragment (a card). No <html> and no sidebar.
  • Target: #book-slot.
  • Swap: innerHTML. The children of #book-slot are replaced.

Experiment

Click the button, then look at the address bar. It should still be /ui/tutorial/2. In the network panel, open the card response and confirm it is only the card, not a full page.
